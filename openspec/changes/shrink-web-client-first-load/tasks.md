## 6. Bytecode-only QML measurement

- [x] 6.1 Build `decenza-web` with `QT_QMLCACHEGEN_ARGUMENTS --only-bytecode` and record its Brotli q11 size against the AOT build. Verified by both sizes recorded in the evaluation (measured at q9 for all three variants: 17,128,727 against 19,139,861 for AOT `-O3`, −2.01 MB).
- [x] 6.2 On the iPhone, measure both builds against the input budget (p95 ≤ 100 ms over 30 interactions on the home screen and recipe editor) and the graph budget (p95 frame ≤ 33 ms on a 60 s live or replayed extraction). Keep `--only-bytecode` only if both budgets hold and the saving is at least 2 MB compressed; otherwise remove it. Verified by the recorded numbers and decision in the evaluation and the build file reflecting that decision. **Rejected 2026-10-27, before the budgets:** the bytecode-only client never connects its domain services (the `services` list in `qml/webclient/Main.qml` reaches C++ empty, with no QML error), so every page stops at "Profiles are disconnected" in iOS Safari and Edge. The AOT rebuild of the same tree loads. The switch was removed from `src/webclient/CMakeLists.txt`.
- [x] 6.3 Link the release Wasm with `-Os` and with `-Oz` instead of the current speed-optimized link, record each Brotli q11 size, and apply the 6.2 budgets on the iPhone. Keep the smallest variant that holds both budgets (combined with the 6.2 decision). Verified by the recorded sizes, numbers and decision, and the build file reflecting it. **Rejected 2026-10-26, no runtime trial needed:** release-style `-O3` is 80,239,417 bytes raw / 19,139,861 Brotli q9; compiling and linking with `-Oz` gives 67,919,060 raw (−15%) but 18,732,090 Brotli (−0.41 MB, −2%), far under the 2 MB bar, and `-Os` lies between the two. The trial switch was removed.
