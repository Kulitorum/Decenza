## REMOVED Requirements

### Requirement: Migration off user-created heater-off presets
**Reason**: The migration shipped in 2.0.3. Every installation at or above the upgrade floor (2.0.7) has already run it, and settings exports from 2.0.7 onward carry no user-created heater-off presets.
**Migration**: Install Decenza 2.1.0 first to bring older settings past this step.
