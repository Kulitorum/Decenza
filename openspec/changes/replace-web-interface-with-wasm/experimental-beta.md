## CI resource correction

The maintainer identified the per-platform Wasm producer as a build-resource regression. The replacement is one `release.yml`, accepting `platforms=all` or a comma/space-separated list. Its single Wasm producer and selected native jobs start together. Native compilation initially defers embedding; the shared finish action waits for the same run's producer, verifies the downloaded artifact, and enables PREBUILT embedding before final packaging. The embedding define now applies only to `shotserver_webclient.cpp`, avoiding a target-wide compile-flag change at that boundary. The native-only unsupported branch marks its unused request explicitly. Existing caches and post-save pruning remain in place; final CMake regeneration precedes iOS widget injection.

Old Android run **39980730744**, on commit `b1260f1a`, passed Wasm (13 m 48 s) but failed native compilation because `historyservicesource.h` used `QPointer` without including its definition. Its cascading inheritance diagnostics followed that first error. The direct include is now added; a source audit found no other header with that omission. This fix and the consolidated workflow still require fresh CI validation. Workflow linting and an independent read-only review pass; neither is claimed as a build. Remaining platform/install validation holds stay unchecked.

Wasm compiler caching now covers Qt Multimedia, Qt Remote Objects and the application through Emscripten's Clang wrapper, with a 500M cap and real-call checks for both phases. The shared cache helper's opt-in budget check leaves existing native behavior unchanged and reserves 4 GiB headroom plus 1 GiB of SDK growth before admitting Wasm persistence. Initial actual entries total 3.687 GiB; cache-hit rates and peak concurrent usage remain unverified until the all-platform run. macOS remains uncached.

All-platform run **39986561764** exposed a Qt Multimedia Wasm source dependency on its precompiled header: disabling PCH for caching left `QMap` undefined in `qwasmjs.cpp`. CI now retains PCH and uses ccache's documented Clang PCH settings instead; no Qt source patch is applied. Before the failure, ccache recorded 124 cacheable calls, all cold misses. Both Qt SDK downloads were cache hits; the host-tools step spent most of its 4 m 13 s installing desktop dependencies, which are now disabled in favor of the explicit minimal prerequisites. Android's native library compiled and linked successfully before reaching the failed producer gate; no package was accepted. A replacement all-platform run is required.
