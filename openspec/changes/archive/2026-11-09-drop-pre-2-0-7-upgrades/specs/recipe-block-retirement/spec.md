# Spec Delta

## REMOVED Requirements

### Requirement: A one-time upgrade brings saved profiles to the new shape
**Reason**: The one-time pass shipped in 2.0.1. Every installation at or above the upgrade floor (2.0.7) has already run it. A profile that still carries a block, such as one imported or sideloaded later, is handled by the remaining "A stored block is removed on sight" requirement.
**Migration**: None.
