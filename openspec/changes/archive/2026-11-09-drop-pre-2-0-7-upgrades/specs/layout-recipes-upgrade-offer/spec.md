# Spec Delta

## REMOVED Requirements

### Requirement: One-time upgrade offer for existing users
**Reason**: The offer targets layouts carried over from releases before 2.0.0. Every installation at or above the upgrade floor (2.0.7) has already been offered it.
**Migration**: None. Users can reset to the recipes-first default from the layout editor.

### Requirement: Accept-path layout transform preserves customizations
**Reason**: It is part of the removed upgrade offer.
**Migration**: None.

### Requirement: Layout transform runs once
**Reason**: It is part of the removed upgrade offer.
**Migration**: None.

### Requirement: Starter recipe from the last shot
**Reason**: It is part of the removed upgrade offer. Creating a recipe from a shot remains available through the existing promote-from-shot path.
**Migration**: None.

### Requirement: Drink type is chosen in the upgrade dialog
**Reason**: It is part of the removed upgrade offer.
**Migration**: None.
